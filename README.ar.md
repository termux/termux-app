# Termux — نظرة عربية على المساهمة المقترحة

[English](README.md) | العربية

[Termux](https://termux.dev) تطبيق طرفية وبيئة Linux لنظام Android. هذا فرع مبني على [المصدر الأصلي](https://github.com/termux/termux-app)، لنقل تحسينات النموذج العربي السابق إلى أساس حديث واقتراحها للمراجعة. **ليس إصداراً رسمياً أو مساهمة وافق عليها مشرفو Termux.**

## ما الذي يقترحه هذا الفرع؟

- تبقى الإنجليزية لغة التطبيق عند البدء، مع مبدّل بين English والعربية وترجمات عربية للواجهة باستخدام لغات التطبيق في AndroidX.
- عرض عربي اختياري من اليمين إلى اليسار، مع وصل الحروف والنص المختلط، على Android 6 / API 23 فأحدث: تدفق كامل للصف في النص العادي بالشاشة الأساسية، وحقول RTL محدودة بخلاياها المشغولة الأصلية في الشاشة البديلة وتتبع الفأرة ووضع مفاتيح التطبيق والصفوف الشبكية أو المزاحة للداخل أو ذات التعداد.
- تُحفظ الترويسات والتذييلات وبادئات ASCII والحدود ومفاتيح الأسهم وHome/End الأصلية في واجهات الطرفية. لا عكس للواجهة كاملة ولا محاذاة إلى يمين الشاشة كلها؛ المضيف يملك الشبكة. يبقى الرسم الأصلي مطابقاً عند التعطيل، ويحتفظ API 21/22 بمسار `drawText` الأصلي دون تغيير.
- يفتح زر **English/العربية** الظاهر في درج التنقل قائمة اختيار اللغة. تغيير اللغة فعلياً يمسح اختيار التدفق اليدوي المحفوظ: العربية تفعّل التدفق افتراضياً، والإنجليزية تعطّله؛ إعادة اختيار اللغة نفسها لا تمسحه.
- أولوية التحكم: قيمة صريحة صالحة للخاصية `terminal-rtl-text-shaping`، ثم اختيار قائمة السياق المحفوظ عبر إعادة التشغيل والتدوير، ثم افتراضي اللغة. الخاصية الصالحة تعطّل مفتاح القائمة؛ غيابها أو عدم صلاحيتها لا يتجاوز سياسة اللغة.
- تغيير لغة الواجهة لا يترجم مخرجات الصدفة أو البرامج، ولا يغيّر ترتيب النص المخزّن أو الأوامر. ترجمة موارد التطبيق والواجهة المشتركة وعرض الطرفية مستمرة؛ بعض الرسائل الإنجليزية الأصلية والمساعدة الخارجية لم تُترجم.

## إصلاح واجهات الطرفية — 2026-09-08

تبقى الرموز اللاتينية والرقمية السابقة للعربية بالرسم الأصلي، بما يحفظ عمود `TIME+` في htop؛ وتظل اللاتينية والأرقام المضمّنة بعد العربية داخل الحقل خاضعة لـ Bidi. يراعي المؤشر والتحديد والفأرة حدود الحقل. يُمنع رسم المحارف والمؤشر الأصليين المستبدلين قبل تحويلهما إلى بكسلات، لتجنّب تكرار امتدادات الحروف وآثارها. أُصلح إحداثي بروتوكول الفأرة الخام للخلايا العريضة وأصبح البحث عن الحقول بزمن خطي O(n).

**نجحت اختبارات فعلية لـ nano 8.3 و9.1 عبر PTY:** السهم الأيمن مرتين، ثم إدراج وDelete وBackspace وحفظ، مع مطابقة ملف UTF-8 المتوقع. نجح أيضاً عرض أمر عربي في **htop 3.2.1**. اجتازت المخرجات إعادة التمرير عبر محاكي Termux وAndroid Canvas الأصلي على API 28/34. أُعيد إنتاج نمط شبيه بلقطة Claude Code بنموذج **اصطناعي** وأُصلحت أسطر المتابعة المزاحة للداخل؛ لم تُختبر جلسة فعلية موثّقة الدخول من البداية إلى النهاية لـ Claude Code أو Codex. هذه أدلة للحالات المختبرة، لا اعتماد رسمي للتوافق ولا موافقة مشرفي Termux.

راجع [دليل الميزات والتحكم والحدود](docs/arabic/README.ar.md) أو [الدليل الإنجليزي](docs/arabic/README.en.md)، و[الأدلة](docs/arabic/UPSTREAM_PR.md#validation) و[VALIDATION.json](docs/arabic/VALIDATION.json) للنتائج المجمعة الحالية بدلاً من أعداد جولات سابقة. تبقى فحوص الأجهزة وخطوط المصنّعين ولوحات المفاتيح وIME وسحب مقابض التحديد قيد الانتظار. كشف الحقول استدلالي؛ قد لا يميّز كل عناصر الواجهة المستقلة التي تفصلها مسافة واحدة فقط. هذه ليست نتائج النموذج السابق.

## التثبيت والمساهمة والترخيص

- [README الأصلي بالإنجليزية](README.md) هو المرجع لتعليمات التثبيت والتصحيح وروابط المشروع. شاراته تشير إلى حالة المشروع الأصلي، لا إلى نجاح اختبارات هذا الفرع.
- خذ نسخة احتياطية قبل تغيير مصدر التثبيت؛ لا تخلط التطبيق وإضافاته من مصادر ذات مفاتيح توقيع مختلفة. نجاح البناء الأولي لا يعني اعتماد إصدار نهائي.
- **عطّل GitHub Actions في أي فرع GitHub جديد قبل نشر الإصدارات.** بعض إجراءات الإصدار الموروثة قد تحذف الإصدار ووسمه عند الفشل أو تستهدف مستودع Termux الرسمي؛ راجع [سلامة النشر](docs/arabic/UPSTREAM_PR.md#fork-publication-safety). لا تغيّر إجراءات المشروع الأصلي في الرقعة الأساسية.
- [مسودة طلب الدمج](docs/arabic/UPSTREAM_PR.md) معدّة للنقاش أولاً؛ قبول المساهمة قرار مشرفي المشروع، وليس مضموناً.
