# VorbisLib ARM64 integration

VorbisLib 1.1.0 is a **user-supplied external library**. The Android project expects:

- `app/src/main/cpp/prebuilt/arm64-v8a/libvorbislib.so`
- `app/src/main/cpp/include/vorbislib.h`

These are not generated by TypeScript. For repeatable builds, provide both using the **VorbisLib-android-arm64-v8a.zip** archive, preserving license notices. The library is BSD-3-Clause and includes third-party components with their own terms. This branch does not redistribute the binary until those files are explicitly uploaded.

The optional NDK module is built only for arm64-v8a and only when the shared library exists. Otherwise the Java app stays installable, and `MLBBNativeVorbis.available()` returns false.

The JNI API exposes `encode(wavOrOgg, quality, maxFrames)` and `decodeToOgg(wem, legacyCodebooks)`. It uses the library's modern Custom Vorbis format (codec 0xFFFF). The native library reports API 21+ and bundled validation samples; **MLBB in-game playback is not verified**. Conversion from MP3 or FLAC must first decode to WAV. Unsupported stereo/sample rates must fail rather than silently produce incompatible output.

After putting binaries in place, rebuild with the MLBB Editor GitHub Actions workflow. Test newly encoded WEMs with vgmstream and an original target MLBB bank before allowing automatic Shizuku installation. Keep the original .bak file.
